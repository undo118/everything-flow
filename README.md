# Everything Flow 🌀

**带文件追踪的协作流程图工具**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Built with tldraw](https://img.shields.io/badge/built%20with-tldraw-6c63ff)](https://tldraw.dev)

</div>

---

Everything Flow 是一个**可视化流程图编辑器**，让非技术人员也能轻松拖拽画出协作流程图。每个节点可以结构化地表示"人 + 任务 + 文件"，适合团队协作场景下的流程梳理、文件流转追踪。

> ⚡ **零配置即用** — 下载后双击即打开浏览器，不需要安装任何编程环境。

---

## 🚀 快速开始

### Windows
1. 下载项目文件夹
2. **双击** `run.bat`
3. 等待几秒钟，**浏览器自动打开** → 看到画布即成功
4. ⚠️ 弹出的小黑窗**不要关**，那是服务在后台运行

### Mac / Linux
```bash
cd everything-flow
chmod +x run.sh
./run.sh
```

### 手动打开
如果浏览器没自动弹出，在地址栏输入 `http://localhost:3000`。

## 📖 使用指南

### 界面概览

```
┌──────────────────────────────────────────────┐
│  Everything Flow  协作流程图工具              │
│  [➕ 添加节点] [📂 加载] [💾 保存]           │
├──────────────────────────────────────────────┤
│                                              │
│     ┌──────────┐                             │
│     │  新节点   │    ← 流程图节点             │
│     │          │                             │
│     └──────────┘                             │
│                                              │
│                画布区域                       │
│                                              │
└──────────────────────────────────────────────┘
```

### 基本操作

| 操作 | 方法 |
|------|------|
| **添加节点** | 点击工具栏的 `➕ 添加节点` |
| **移动节点** | 按住节点拖动 |
| **编辑内容** | **双击节点** → 弹出编辑窗口 → 填写内容 → 保存 |
| **调整大小** | 拖拽节点边缘的小方块 |
| **平移画布** | 按住鼠标右键拖动 |
| **缩放** | 滚动鼠标滚轮 |

### 画连线（箭头）

1. 鼠标移到节点边缘，出现 **4 个小圆点**（上下左右）
2. 在任意小圆点上**按住鼠标左键**
3. 拖到**另一个节点的小圆点**上松开
4. 一条带箭头的紫色连线就画好了 🎯

### 保存 & 加载

- **保存** 💾 → 下载 `.json` 文件，存好下次继续用
- **加载** 📂 → 选择之前保存的 `.json` 文件，恢复画布
- ⚠️ 加载新文件会**替换**当前内容，记得先保存

### 节点字段说明

每个节点可包含以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **标题** | 节点名称 | `# 需求评审` |
| **责任人** | 谁负责 | `张三` |
| **任务** | 做什么 | `审核需求文档` |
| **输入** | 需要什么材料 | `需求初稿 v1.2` |
| **输出** | 产出什么 | `评审通过纪要` |
| **版本** | 版本号 | `v1.0` |
| **状态** | 进度 | `待开始 / 进行中 / 已完成` |

> 💡 **Markdown 支持**：标题内容支持 Markdown 语法（`# 标题`、`**加粗**`、`- 列表` 等）。

---

## 💡 小贴士

- 画完**及时保存**，浏览器刷新会丢失未保存内容
- 建议 `.json` 文件取有意义的名字（如 `项目A-需求阶段-v2.json`）
- 小黑窗保持开着，关掉工具就停了
