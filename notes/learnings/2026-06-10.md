## 收获

- **SVG→Image→Canvas 管道的重要限制**: `foreignObject` 在 Image 上下文不可靠（Chrome 92+ 才支持部分场景，Safari/Firefox 不支持）。替代方案：
  1. 纯 SVG 元素（text, tspan） — 最兼容
  2. `dom-to-image` / `html2canvas` 库 — 但依赖重
  3. Canvas API 直接绘制 — 全自控
- `XMSerializer.serializeToString()` 对 XML 要求严格，HTML 内容可能产生不可预见的序列化问题
- SVG 导出需要显式设置 `width`+`height`（除 viewBox 外）才能可靠作为 `<img>` 加载
