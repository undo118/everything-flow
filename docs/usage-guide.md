# Everything Flow — 使用说明

> 本说明面向**非编程人员**，用最简单的话告诉你如何上手这个工具。

---

## 一、怎么打开这个工具

### Windows 用户
1. 打开 `everything-flow` 文件夹
2. **双击** `run.bat`（一个文件图标，名称是 run.bat）
3. 会弹出一个黑色的命令行窗口，等几秒钟
4. **浏览器会自动打开**，看到画布界面就说明成功了
5. **注意：** 黑色的命令行窗口**不要关**，关掉工具也会关掉

### Mac 用户
1. 打开终端（Terminal）
2. 输入 `cd `（后面加空格），然后把 `everything-flow` 文件夹拖进终端窗口，回车
3. 输入 `./run.sh`，回车
4. 浏览器自动打开，看到画布就成功了

### 如果没自动打开浏览器
在浏览器地址栏输入 `http://localhost:3000`，回车即可。

## 二、界面介绍

打开后你会看到：

```
┌──────────────────────────────────────────────┐
│  Everything Flow  协作流程图工具              │
│  [➕ 添加节点] [📂 加载] [💾 保存]           │
├──────────────────────────────────────────────┤
│                                              │
│     ┌──────────┐                             │
│     │  新节点   │    ← 这是流程图节点         │
│     │          │                             │
│     └──────────┘                             │
│                                              │
│                    画布区域（白色背景）        │
│                                              │
└──────────────────────────────────────────────┘
```

- **顶部工具栏**：添加节点、加载文件、保存文件
- **中间大片区域**：画布，在上面画流程图
- **节点**：矩形块，代表一个人、一个任务或一个环节

---

## 三、基本操作

### 添加节点
点击顶部工具栏的 **➕ 添加节点** 按钮，画布中间就会出现一个新的节点方块。

### 移动节点
直接用鼠标**按住节点**拖动，放到你想要的位置。

### 编辑节点内容
**双击节点**，会弹出一个编辑窗口。在编辑窗口中可以：
- 写标题和内容（支持 Markdown 格式）
- 填写字段信息（责任人、任务、输入、输出、版本、状态等）
- 填写完成后点击 **保存** 关闭窗口

> 💡 **Markdown 是什么？** 就是你在聊天软件里用的那种简单排版，比如 `# 标题` 是大字，`**加粗**` 是加粗，`- 列表` 是圆点列表。

### 缩放画布
- **滚动鼠标滚轮**：放大 / 缩小
- **按住鼠标右键拖动**：平移画布（就像用手在手机上滑动地图一样）

### 调整节点大小
把鼠标移到节点边缘，出现小方块，**按住拖拽**即可改变大小。

---

## 四、连线（箭头）

节点之间画箭头表示"文件传递"或"流程关系"。

### 画一条线
1. 鼠标移到节点边缘，会看到 **4 个小圆点**（上下左右各一个）
2. 在任意一个小圆点上**按住鼠标左键**
3. 拖到**另一个节点的小圆点**上松开
4. 一条线就连上了！

### 连线说明
- 线是紫色的，箭头表示方向
- 从哪个小圆点拖出就代表从哪个方向出发
- 一条线连的是"两个节点的某个边"，不是连整个节点

---

## 五、保存和加载

### 保存你的流程图
1. 点击工具栏的 **💾 保存** 按钮
2. 浏览器会下载一个 `.json` 文件（文件名类似 `everything-flow-20260606.json`）
3. 把这个文件存好，下次继续用

### 加载之前保存的流程图
1. 点击工具栏的 **📂 加载** 按钮
2. 选择之前保存的 `.json` 文件
3. 画布就会恢复到之前的样子

> ⚠️ **重要提示**：加载新文件会**替换**当前画布上的所有内容。如果你当前画布有东西，记得先保存再加载。

## 六、节点内容详解

每个节点可以包含以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **标题** | 节点的名称，用 `# 标题` 写在最前面 | `# 需求评审` |
| **责任人** | 负责这个环节的人 | `张三` |
| **任务** | 这个环节要做什么 | `审核需求文档` |
| **输入** | 需要什么材料才能开始 | `需求初稿 v1.2` |
| **输出** | 完成后会产出什么 | `评审通过纪要` |
| **版本** | 当前版本号 | `v1.0` |
| **状态** | 当前进度 | `待开始` / `进行中` / `已完成` |

## 七、常见问题

**Q: 不小心删除了节点怎么办？**
A: 当前版本不支持撤销（Ctrl+Z），所以删除前请确认。如果不小心删了，可以重新添加。

**Q: 我不想用已保存的版本了，怎么重新开始？**
A: 新建一个浏览器标签页，重新打开 http://localhost:3000 即可。如果之前保存过内容，可以点"加载"恢复。

**Q: 连错线了怎么办？**
A: 当前版本暂不支持删除连线。建议重新创建一个新的流程图文件。

**Q: 为什么双击节点没反应？**
A: 确保你是在节点的**内部**双击，不是在标题栏或画布空白处。

**Q: 字太多显示不全怎么办？**
A: 拖拽节点边缘放大节点，或者双击编辑后精简内容。

---

## 八、温馨提示

- 画完后记得**及时保存**（💾 按钮），浏览器刷新或关闭会导致未保存的内容丢失
- 建议给你的 `.json` 文件取有意义的名字，比如 `项目A-需求阶段-v2.json`
- 黑色的命令行窗口是后台在运行服务，保持它开着，不要关
