## 核心概念

### 什么是正交路由

箭头路径只包含水平（→）和垂直（↓↑）线段，每段之间 90° 转角。没有斜线。

### 延伸方向规则

延伸方向取决于**连接的方向**（朝对方走），而不是 dot 的朝向：

| 连接方向 | A.dot | A 延伸方向 | B.dot | B 延伸方向 |
|----------|-------|-----------|-------|-----------|
| bottom→top | A.bottom | 向下（朝 B） | B.top | 向上（朝 A） |
| top→bottom | A.top | 向上（远离 B） | B.bottom | 向下（远离 B） |

### 通用参数

- **节点尺寸：** 宽 180px，高 80px
- **箭头线宽：** 2.5px（选中时 3.5px）
- **箭头颜色：** `#6c63ff`（未选中），`#ff6b6b`（选中）

## Case 1：bottom→top 竖直对齐 ✅ 已通过

### 场景

节点 A 在正上方，节点 B 在正下方，X 坐标完全对齐。

### 参数

```
A = (200, 100), 宽 180, 高 80
B = (200, 300), 宽 180, 高 80

A.bottom = (290, 180)
B.top   = (290, 300)
```

### 路径算法

两节点完全对齐时，水平偏移量为 0，路径退化为**单段竖直线**：

```
A.bottom → B.top（直线）
```

### 段数

1 段（直连，无水平偏移）

---

## Case 2：bottom→top 竖直不对齐 ✅ 已通过

### 场景

节点 A 在左上方，节点 B 在右下方，X 坐标错开。

### 参数

```
A = (120, 100), 宽 180, 高 80
B = (270, 300), 宽 180, 高 80

A.bottom.x = 210, A.bottom.y = 180  (y₁)
B.top.x    = 360, B.top.y    = 300  (y₂)
```

### 路径算法（3 段 L 型）

```
① A.bottom → 向下延伸到 y
② → 水平右移到 B.top.x
③ → 向下进 B.top
```

其中 y 的取值范围为 **[y₁, y₂]**，即 [A.bottom.y, B.top.y]。

**默认值：** y = (y₁ + y₂) / 2（两 dot 的中点）

### 拖拽手柄

横向线段上有一个可拖拽的交互手柄，用于视觉调整 y 值。

**手柄设计要求：**

| 属性 | 值 |
|------|-----|
| 方向 | 平行于线段（横向） |
| 形状 | 矩形 + 两端半圆（药丸形 / capsule） |
| 高度 | 线宽 × 3 = 7.5px |
| 全长 | 线宽 × 8 = 20px |
| 颜色 | `#ff8844`，透明度 0.85 |
| 边框 | 白色 1px |
| 光标 | `ns-resize` |
| 位置 | 横向线段的中点 |
| 拖拽范围 | y ∈ [y₁ + 2, y₂ - 2]（留出边界余量） |

### 段数

3 段 L 型

---

## 拖拽手柄通用规范（适用于所有 case）

所有带可拖拽横向段的路由都遵循以下手柄设计：

1. **方向：** 平行于可拖拽的线段
2. **形状：** 矩形 + 两端半圆（capsule）
3. **高度 = 线宽 × 3**
4. **全长 = 线宽 × 8**
5. **颜色：** `#ff8844`，白色边框
6. **光标：** 指示可拖拽方向（横向线段用 `ns-resize`，竖向线段用 `ew-resize`）
7. **位置：** 所在线段的中点
8. **拖拽范围：** 限制在对应的两个端点之间
9. **每次拖动后实时重绘路径**

## Case 4：bottom→top B 在 A 正上方 ✅ 已通过

### 场景

B（右节点）移动到 A（左节点）正上方，同 X 坐标。连接仍是 A.bottom → B.top。

### 参数

```
A = (80, 200), 宽 180, 高 80
B = (80, 80),  宽 180, 高 80  （同 X，B 在 A 正上方）

A.bottom = (170, 280)
B.top    = (170, 80)

Ar = 260, Br = 260
Al = 80,  Bl = 80
```

### 路径算法

与 Case 3 相同的 5 段公式，但竖线③有特殊规则：

```
① A.bottom → ↓30px
② → → 到 vert3X
③ → ↑ 到 horiz4Y
④ → → 到 B.top.x
⑤ → ↓ 进 B.top
```

### 竖线③的约束（与 Case 3 不同）

| 规则 | 值 |
|------|-----|
| 默认位置 | 节点右侧 30px = max(Ar, Br) + 30 = **290** |
| 允许范围 | ≤ min(Al, Bl) **或** ≥ max(Ar, Br) |
| 禁区 | 两节点之间的 X 范围（不允许穿越节点） |
| 拖拽光标 | `ew-resize` |
