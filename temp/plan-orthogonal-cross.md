# 正交对角路由 — 设计 & 实现计划

## 什么是正交对角（Cross-Direction）

源点和目标点在垂直的轴上（即 A.bottom → B.left），两者的发射/接收方向成 90°，目前回退到直线。

### 8 种对角组合

| 源 dot | 目标 dot | 源发射方向 | 目标接收方向 |
|--------|---------|-----------|-------------|
| top    | left    | ↑ (向上)   | ← 从左侧进入 |
| top    | right   | ↑ (向上)   | → 从右侧进入 |
| bottom | left    | ↓ (向下)   | ← 从左侧进入 |
| bottom | right   | ↓ (向下)   | → 从右侧进入 |
| left   | top     | ← (向左)   | ↑ 从顶部进入 |
| left   | bottom  | ← (向左)   | ↓ 从底部进入 |
| right  | top     | → (向右)   | ↑ 从顶部进入 |
| right  | bottom  | → (向右)   | ↓ 从底部进入 |

## 路由模式

对角路由总是 4 段（5 个点），因为第 1 段必须沿源发射方向，最后一段必须沿目标接收方向，两者垂直所以需要 4 段过渡。

### 模式 A：源垂直 → 目标水平（4 段 L 型+U 型混合）

```
① 从源 dot 沿发射方向延伸 EXT
② 水平转弯到中间 x
③ 垂直转弯到目标 y
④ 水平进入目标 dot（方向匹配目标接收方向）
```

**示例：A.top → B.left**
```
A.top = (200, 100), B.left = (160, 300)
① A.top → (200, 100 - 30) = (200, 70)   [向上]

// 看目标在源的哪一侧来决定②的方向
// B 在 A 左侧：turn left
② (200, 70) → (160, 70)                 [向左]
③ (160, 70) → (160, 300)                [向下]
④ (160, 300) → (160, 300) = B.left      [向右，进入 B.left]
// 注意④是退化的(0长度)：B.left.x === pt3.x，即已经对齐

// 需要保证 pt3.x < bX（从左侧进）
// 所以②向左到 bX 或更左
```

### 模式 B：源水平 → 目标垂直（4 段，旋转 90°）

```
① 从源 dot 沿发射方向延伸 EXT
② 垂直转弯到中间 y
③ 水平转弯到目标 x
④ 垂直进入目标 dot（方向匹配目标接收方向）
```

## 拖拽手柄

4 段路径 = 3 个中间手柄（h2, h3, h4）：
- 手柄在②③④段的中点上
- 最中间的段（③）的手柄类型与段方向一致
- 靠近源和目标的段（②④）各有一个手柄
