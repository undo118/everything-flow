# 正交对角路由 — 通用算法

## 分类

8 种对角组合按**源发射方向**分为两类：

### A. 源垂直 → 目标水平（A.top/A.bottom → B.left/B.right）
路径：**垂直 → 水平 → 垂直 → 水平**（4 段）
- h2 控制 Y（纵向拖，ns-resize）
- h3 控制 X（横向拖，ew-resize）
- 最后一段方向：B.left=→右, B.right=←左

### B. 源水平 → 目标垂直（A.left/A.right → B.top/B.bottom）  
路径：**水平 → 垂直 → 水平 → 垂直**（4 段）
- h2 控制 X（横向拖，ew-resize）
- h3 控制 Y（纵向拖，ns-resize）
- 最后一段方向：B.top=↓下, B.bottom=↑上

---

## 核心判定逻辑（以 A.top → B.left 为例已验收）

### 条件 1：B 全在源发射方向的哪一侧？

**源向上（top）：**
- `Bb.y <= At.y` → B 全在 A 上方 → 水平段取中点 `(At.y + Bb.y) / 2`
- `Bb.y > At.y` → B 延伸到 A 下方 → 水平段在 `min(At.y, Bt.y) - 30`

**源向下（bottom）：**
- `Bt.y >= Ab.y` → B 全在 A 下方 → 水平段取中点 `(Ab.y + Bt.y) / 2`
- `Bt.y < Ab.y` → B 延伸到 A 上方 → 水平段在 `max(Ab.y, Bb.y) + 30`

**源向左（left）：**
- `Br.x <= Al.x` → B 全在 A 左侧 → 垂直段取中点 `(Al.x + Br.x) / 2`
- `Br.x > Al.x` → B 延伸到 A 右侧 → 垂直段在 `min(Al.x, Bl.x) - 30`

**源向右（right）：**
- `Bl.x >= Ar.x` → B 全在 A 右侧 → 垂直段取中点 `(Ar.x + Bl.x) / 2`
- `Bl.x < Ar.x` → B 延伸到 A 左侧 → 垂直段在 `max(Ar.x, Br.x) + 30`

### 条件 2：目标在垂直线段的哪侧？

**B.left（← 从左侧进，最后一段 → 右）：**
- `Bl > Ar` → 无重叠 → 垂直线段在 `(Ar + Bl) / 2`（两节点中间）
- `Bl <= Ar` → 有重叠 → 垂直线段在 `min(A.x, B.x) - EXT`（绕左侧）

**B.right（→ 从右侧进，最后一段 ← 左）：**
- `Br < Al` → 无重叠 → 垂直线段在 `(Al + Br) / 2`（两节点中间）
- `Br >= Al` → 有重叠 → 垂直线段在 `max(A.r, B.r) + EXT`（绕右侧）

**B.top（↑ 从顶部进，最后一段 ↓ 下）：**
- `Bt > Ab` → 无重叠 → 水平线段在 `(Ab + Bt) / 2`
- `Bt <= Ab` → 有重叠 → 水平线段在 `max(A.b, B.b) + EXT`（绕下方）

**B.bottom（↓ 从底部进，最后一段 ↑ 上）：**
- `Bb < At` → 无重叠 → 水平线段在 `(At + Bb) / 2`
- `Bb >= At` → 有重叠 → 水平线段在 `min(A.t, B.t) - EXT`（绕上方）

---

## 退化：2 段

当源和目标在同一方向且路径直接可行时不需绕行：
- **A.top → B.left 退化**：B 在上方 (`bY < aY`) 且 B 在右侧 (`aX < bX`)
- 同理其他方向

## 手柄

4 段路径只有 **2 个手柄**（h2, h3），最后一段直连目标不设手柄：
- h2：在第二段（连接延伸段到中间段）的中点
- h3：在第三段（中间段到目标入口段）的中点
